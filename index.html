Why classical physics failed

Treating the cavity's standing electromagnetic modes classically, each mode gets an average energy of kT (equipartition). Because the number of modes per unit wavelength grows as 1/λ⁴, the predicted radiance diverges as λ → 0:

BRJ(λ,T) = 2ckT / λ⁴

Integrated over all wavelengths this predicts infinite emitted power from any warm object — the ultraviolet catastrophe. Real ovens, filaments, and stars obviously don't do this, so the model itself had to be wrong.

1900, Planck

The quantum fix

Planck found the data fit only if a mode's energy is restricted to discrete multiples of hν. At short wavelengths that quantum is so large compared to kT that those modes are almost never excited, which suppresses the divergence:

B(λ,T) = (2hc²/λ⁵) · 1 / (e^(hc/λkT) − 1)

As λ grows, hc/λkT → 0 and this expression reduces exactly to the Rayleigh–Jeans line above — the classical result was the correct long-wavelength limit of a deeper quantum law, not a wrong theory outright.
