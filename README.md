# Blackbody Radiation — Cavity, Curve, and the Quantum Fix

An interactive lecture demo of blackbody radiation: drag the temperature slider and watch the Planck spectrum shift (Wien's law) and grow (Stefan–Boltzmann, T⁴), compared against the classical Rayleigh–Jeans prediction and its ultraviolet catastrophe.

**Live page:** https://shanem73.github.io/blackbody-radiation/

## Features
- Animated cavity radiator with an approximate apparent color (dark below the ~800 K Draper point)
- Planck vs. Rayleigh–Jeans spectral radiance on fixed axes, so position and height changes are physical
- Optional logarithmic y-axis, and an extended log wavelength axis (10 nm → 20 mm) that shows the 2.7 K CMB
- Presets: CMB, lava, incandescent bulb, halogen lamp, Sun, Sirius A, Rigel
- Live readouts for Wien peak wavelength and Stefan–Boltzmann emitted power

Single self-contained `index.html` — open it in any modern browser, no build step.
